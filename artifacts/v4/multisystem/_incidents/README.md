# Multisystem V4 protocol incidents

`h6-1.5-protocol-v1-preliminary/summary.json` is the immutable preliminary
output produced under protocol v1. It is not a final scientific result.

Audit found that 9,792 known symbolic composition conflicts were reported by
the generic search counter as candidate numerical failures, and that
surrogate-eligible Hessian-quality rejections did not persist their individual
failed checks. Protocol v1.1 corrects this provenance without pruning those
states or changing candidates, ranking, resource metrics, optimization, or
the preliminary outcome. It also adds a strictly stronger, molecule-independent
final guard that prevents an accepted candidate from leaving chemical accuracy.
