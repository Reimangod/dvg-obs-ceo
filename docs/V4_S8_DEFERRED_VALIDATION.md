# V4-S8 deferred validation gate

V4-S8 is deliberately recorded as `deferred-not-passed`. The current project
has no unseen molecule with a matched, frozen CEO* checkpoint, and the approved
scope excludes new CEO* and ordinary ADAPT executions.

The successful LiH result is development evidence because LiH and its earlier
single-candidate outcome were already observed while designing V3/V4. Calling
it blind validation would be academically incorrect.

A future confirmatory run needs a separate pre-execution protocol fixing the
system-selection rule, checkpoint-selection rule, source-generation authority,
and unchanged V4 configuration. One unseen system would support only a limited
validation result; broader claims require at least two systems or one molecule
at two geometries.
