# Implementation plan

The normative implementation plan is
[`DVG_OBS_CEO_REBUILD_PLAN.md`](DVG_OBS_CEO_REBUILD_PLAN.md).

Its SHA-256 digest is recorded at S0 completion. Later changes require a new
protocol version; the original must not be overwritten.

The completed S0-S12 plan is followed by the draft successor plan
[`V3_V4_RESEARCH_PLAN.md`](V3_V4_RESEARCH_PLAN.md). The successor becomes
normative only after a separate protocol freeze and tag; it does not alter any
historical V2 result.
